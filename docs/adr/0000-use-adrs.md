# ADR-0000: Use Architecture Decision Records

## Status

Accepted

## Context

mVault v2 is a learning project; decisions must be traceable.

## Decision

Every non-trivial architectural choice is recorded under `docs/adr/` using: Context, Decision, Consequences, Alternatives.

## Consequences

- Slightly more upfront writing
- Easier onboarding and backend swaps later

## Alternatives

- Wiki only (rejected: no version control coupling)
